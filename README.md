**Descripción**

Este programa de práctica solicita el nombre de un estudiante y tres
calificaciones. Luego calcula el promedio y muestra si aprobó o reprobó.

En este ejercicio, un promedio de 70 o más se considera aprobado.

**Cómo ejecutar**

1. Abrir una terminal en la carpeta del proyecto.
2. Ejecutar el comando `dotnet run`.
3. Escribir el nombre y las tres calificaciones.
